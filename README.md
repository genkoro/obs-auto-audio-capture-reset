Windows版OBS Studio用 ／ Luaスクリプト

## 1．使い方

1. 「`obs_auto_audio_capture_reset.lua`」 を好きなフォルダに置きます。
2. OBSの「ツール → スクリプト」を開き「＋」で置いたファイルを追加します。
3. 対象の音源を選び「間隔 (分)」と「動作」を設定します。
4. 後はご自由にお使いください。

## 2．設定項目

**音源**  
リセットする音源を1つ選びます。

**間隔 (分)**  
1～1500分で設定します。  
自動動作が始まってから、設定した間隔が経過したあとに最初のリセットを行います。

**動作**  
次の3つから選びます。

- 録画・配信中のみ（初期値）
- 常時、自動リセット
- 自動リセットしない

**今すぐリセット**  
その場で1回リセットします。動作の設定に関係なく使えます。  
自動動作中に成功すると、そこから間隔を数え直します。

**自動・説明欄**  
次のリセットまでの残り時間、今の状態、前回の結果を表示します。

スクリプトの画面を閉じても、自動動作は続きます。  
音量とミュートは変更しません。

## 3．最初に録画で確認してください

環境によっては、リセット時に「プッ」という小さな音が出ることがあります。

1. 対象のゲームやアプリで音を出した状態で録画を始めます。
2. 「今すぐリセット」を押します。
3. 数秒後に録画を止めて再生し、リセット後も音が出ているか確認します。

確かめる時は、デスクトップ音声を切ってください。  
イヤホンで聞こえる音ではなく、録画ファイルで確認してください。

## 4．困ったとき

**表示：▲ この音源は使えません**  
対処：対象の3種類から選び直します。

**表示：▲ 音声キャプチャがOFF**  
対処：音源のプロパティで「音声をキャプチャ」をONにします。

**表示：▲ 取り込み先が未設定**  
対処：音源のプロパティで、取り込むウィンドウを選びます。

**表示：失敗：スクリプトログ参照**  
対処：「ツール → スクリプト」の「スクリプトログ」で理由を確認します。

**残り時間などの表示が止まった場合**  
スクリプトの画面を開き直してください。  
表示が止まっていても、自動リセット自体は動いています。

表示の「リセットを要求しました」はリセット指示が通ったという意味です。  
音が実際に戻ったかどうかは、録画で確認してください。

## 5．対応環境

趣味で作ったスクリプトの置き場としてここに公開します。必要な方はご自由にお使いください。  
動作保証はありません。

- Windows 10 バージョン2004以降
- OBS Studio 29.1以降（64ビット）  
  作者はOBS 33.0.0で動作を確認しています。

対象にできる音源は、次のいずれか1つです。

- アプリケーション音声キャプチャ
- ゲームキャプチャ
- ウィンドウキャプチャ

マイク、デスクトップ音声、音声入力キャプチャは対象外です。  
追加のインストールは不要です。  
表示はOBSの言語に合わせて、日本語か英語になります。

## 6．更新・削除

**設定の保存**  
設定は、OBSのシーンコレクションごとに保存されます。

**更新する場合**  
録画・配信を止め、新しいファイルで上書きし、スクリプト一覧の「再読み込み」を押します。

**削除する場合**  
スクリプト一覧で選んでゴミ箱を押してから、ファイル自体を削除します。

このスクリプトを複数登録して、同じ音源を操作しないでください。

OBSで取り込んだゲームやアプリの音が、長時間の配信・録画でブツブツすることがあります。  
このスクリプトは、選んだ音源の音声キャプチャを一定の間隔でリセットします。映像の設定は変更しません。

## 7．注意

残り時間の表示と、ゲーム／ウィンドウキャプチャの音声操作には、OBSとQtの内部機能を使っています。  
OBSを更新したら、念のため短い録画で動作を確認してください。
